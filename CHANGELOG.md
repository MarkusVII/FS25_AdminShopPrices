# Changelog

This changelog documents the **public KingMods release** confirmed when this repository starter was prepared. Add future entries only after verifying a release.

## v1.1.0.0

- Expanded the editor to cover six economic price categories.
- Added support for separate buy and sell operations where available.
- Expanded manual controls with BASE, FIXED, Follow Sale, and presets.
- Improved search, filters, displayed prices, and editor behavior.
- Added optional integration with Economy Control.
- Improved supported operations involving resources, productions, and services.

**Official release listing:** https://www.kingmods.net/ru/fs25/mods/84435/tseny-magazina-administratora
