# Support / Допомога

## Before opening an issue / Перед створенням Issue

1. Check that you are using the current public version linked on [KingMods](https://www.kingmods.net/ru/fs25/mods/84435/tseny-magazina-administratora).
2. Test in a **new backup save** or a controlled test setup if possible; do not risk your only save.
3. Note the game version, mod version, multiplayer/single-player mode, and any other economy mods.
4. Reproduce the issue with clear steps. If safe, test with only this mod enabled to narrow down a conflict.
5. Include only relevant log excerpts. Remove names, personal paths, account details, tokens, and other sensitive information.

## Important notes / Важливі примітки

- **Economy Control is optional / Economy Control необов'язковий.**
- **Multiplayer changes depend on server permissions / У мультиплеєрі зміни залежать від прав на сервері.**
- **Third-party price operations are not universally supported / Не всі цінові операції сторонніх модів підтримуються.**

## Submit a report

Use **[🐛 Bug report](https://github.com/MarkusVII/FS25_AdminShopPrices/issues/new?template=bug_report.yml)** or **[💡 Feature request](https://github.com/MarkusVII/FS25_AdminShopPrices/issues/new?template=feature_request.yml)**. You don't need to know programming. The repository collects feedback and ideas only; source code is not available and pull requests are not requested.

**Official ready-to-play download:** [KingMods](https://www.kingmods.net/ru/fs25/mods/84435/tseny-magazina-administratora). GitHub is not an alternate download location.

Do not publish confidential information or private save files without reviewing them first.
